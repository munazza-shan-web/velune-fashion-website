# VELUNE — Contemporary Womenswear Website

A responsive editorial fashion website created as an independent portfolio concept. VELUNE explores the relationship between structure, drape and movement through a refined digital experience.

## Features

- Responsive editorial homepage
- Collection filtering
- Interactive product details and size selection
- Functional demo shopping bag
- Search, mobile navigation and newsletter feedback
- Scroll reveal and subtle hover motion
- Accessible labels, reduced-motion support and semantic HTML
- GitHub Pages ready; no build tools required

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages

1. Upload all files and folders to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for the public link.
