# VELUNE — Contemporary Womenswear Website

VELUNE is a fictional contemporary womenswear label exploring the relationship between structure, drape, movement, and quiet confidence.

This responsive fashion website was created as a portfolio project to demonstrate editorial web design, front-end development, luxury brand presentation, and interactive e-commerce functionality.

## Live Demo

[View the live website](https://munazza-shan-web.github.io/velune-fashion-website/)

## Features

* Contemporary editorial fashion design
* Fully responsive desktop, tablet, and mobile layouts
* Interactive product collection
* Category filtering for tailoring and dresses
* Product-detail popups
* Size selection
* Functional demonstration shopping bag
* Product search panel
* Mobile navigation menu
* Lookbook and brand-story sections
* Fashion journal layout
* Newsletter subscription feedback
* Smooth scrolling and reveal animations
* Accessible semantic HTML
* Reduced-motion accessibility support
* GitHub Pages compatible

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* CSS Grid

* DOM Manipulation

## Run Locally

1. Download or clone the repository:

```bash
git clone https://github.com/munazza-shan-web/velune-fashion-website.git
```

2. Open the project folder.

3. Open `index.html` in your browser or use the VS Code Live Server extension.


## Design Direction

The visual system combines:

* Warm ivory and off-white
* Deep chocolate and black
* Muted brushed-brass accents
* Editorial serif typography
* Structured layouts
* Fluid fashion imagery
* Subtle motion and restrained interactions

The website is designed to feel contemporary, sophisticated, sensual, and quietly luxurious without relying on excessive decoration.
